# Contributing to StructOPE

## Status

StructOPE is at **pre-registration (Protocol v1.0)**. No experiments
have been run. Items 0.2 and 0.8 are BLOCKING and remain open.

## What contributions are welcome

1. **Independent review** of `PROTOCOL.md` and the design documents
   before any confirmatory experiment.
2. **Citation corrections** — missing or incorrect references.
3. **Typo fixes** and minor clarifications.
4. **Threat identification** — additional threats to validity not
   covered by the current register.

## What contributions are NOT accepted at this phase

1. Pull requests adding implementation code (`src/`, `tests/`,
   `experiments/`) before the BLOCKING items are closed.
2. Analysis proposals that assume an OPE estimator is already chosen.
3. Claims of observable benefit. No experiment has been run.
4. Policy-set proposals that bypass Item 0.2.

## How to Contribute

1. Open an issue describing the contribution.
2. Reference the relevant section of `PROTOCOL.md`, `design/`, or
   `preregistration/`.
3. Submit a pull request.
4. Wait for review.

## Falsification-first principle

A contribution that says "this protocol is wrong because X" is more
valuable than a contribution that says "this protocol is right
because Y." The former advances the investigation; the latter does
not.
